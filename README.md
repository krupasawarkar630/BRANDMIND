## 🌟 Overview

**BRANDMIND** is an AI-native brand intelligence platform designed for founders, venture builders, and brand strategists. Traditional branding is slow, subjective, and prone to blind spots. BRANDMIND replaces weeks of agency cycles with a **multi-stage agentic workflow** that:

1. **Interrogates** your core assumptions to eliminate clichés and generic positioning.
2. **Synthesizes** a living **Brand DNA** with deep visual, tonal, and strategic dimensions.
3. **Simulates Multiverses (Brand Worlds)** to test radically different creative archetypes.
4. **Stress-Tests in a Battle Arena** where autonomous AI personas (Gen-Z skeptics, Enterprise buyers, early adopters) challenge the brand.
5. **Locks the Strategic Foundation** with an active **AI Guardian** that automatically enforces brand consistency and rewrites rogue marketing copy.
6. **Deploys a Launch Command Center** with exportable marketing kits, voice guides, and collateral.

## ✨ Key Features

### 🔍 1. Blind Spot & Weak Signal Interrogation
- **Genericity Scanner**: Flags overused buzzwords (*"seamless", "all-in-one", "uber for X"*) and forces founders to specify true differentiation.
- **Flaw Classification**: Analyzes target assumptions, pricing blind spots, and user behavior fallacies.

### 🧬 2. Visual & Semantic Brand DNA
- **Interactive 6-Axis Radar**: Quantifies Differentiation, Audience Fit, Voice Stability, Clarity, Consistency, and Trust.
- **Visual DNA Studio**: Generates live typography pairings, generative geometric shape languages, full color palettes (with WCAG contrast verification), UI styles, and *"Strictly Avoid"* negative constraints.

### 🪐 3. Multiverse Brand Worlds
- Generates 3 distinct brand universes with opposing philosophies (e.g., *Rebellious Challenger*, *Minimalist Pure*, *Community-Centric Companion*).
- Allows side-by-side comparison of naming vectors, voice, positioning, and emotional resonance.

### ⚔️ 4. Autonomous Agent Battle Arena
- AI agents with distinct psychographic profiles debate your brand positioning in real time.
- Produces win probabilities, objection heatmaps, and a **Collective Synthesis Report**.

### 🛡️ 5. Reality Simulator & Crisis Rooms
- Stress-tests your brand against high-stakes scenarios: PR blowbacks, viral copycats, sudden market pivots, and tone drift.
- Tests response strategies against Brand DNA to assess brand trust preservation.

### 🧪 6. Mutation Lab & What-If Machine
- Dual-axis mutation sliders allow granular tuning between opposing traits (*Playful ↔ Authoritative*, *Experimental ↔ Reliable*).
- Instant before/after diff visualizer with semantic impact breakdown.

### 🔒 7. Brand DNA Lock & AI Guardian
- **Immutable Lock**: Seals the brand foundation so downstream creatives cannot deviate without an explicit logged unlock reason.
- **Guardian Scanner**: Scans copy, advertisements, and social posts. Flags violations in real time and offers **1-Click AI Auto-Fixes**.

### 🚀 8. Launch Command Center
- Complete multi-channel collateral hub (Hero headlines, 30s elevator pitches, Product Hunt launch posts, Instagram bios, brand voice guides).
- One-click export to **Markdown**, **JSON**, **Printable PDF**, and **Live Shareable Links**.

## 🛠️ Tech Stack & Architecture

| Layer | Technology | Description |
|---|---|---|
| **Frontend Framework** | [Next.js 16 (App Router)](https://nextjs.org/) | Turbo-packed Server & Client Components |
| **Language** | [TypeScript 5](https://www.typescriptlang.org/) | End-to-end type safety & strict schemas |
| **State Management** | [Zustand](https://github.com/pmndrs/zustand) | Persistent reactive client store with instant demo seeding |
| **Design System** | Custom Vanilla CSS + Design Tokens | Warm Light theme (`#F4F3EF`), Glassmorphism, Micro-animations |
| **Icons & Visuals** | [Lucide React](https://lucide.dev/) | Consistent iconography suite |
| **Database ORM** | [Drizzle ORM](https://orm.drizzle.team/) + PostgreSQL | Multi-tenant schema with project history and audit logging |
| **AI Layer** | Multi-Provider Engine | Modular AI adapter (Claude 3.5 Sonnet / OpenAI / Gemini) + Built-in Mock Intelligence |

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17+ or 20+
- npm, pnpm, or yarn

### 1. Clone the Repository
```bash
git clone https://github.com/krupasawarkar630/BRANDMIND.git
cd BRANDMIND/brandmind-app
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables (Optional)
Create a `.env.local` file in the `brandmind-app` root:
```env
# Optional: Connect your AI Provider (Mock Intelligence runs automatically if omitted)
ANTHROPIC_API_KEY=your_anthropic_api_key
OPENAI_API_KEY=your_openai_api_key
GEMINI_API_KEY=your_gemini_api_key

# Optional: Connect PostgreSQL Database
DATABASE_URL=postgresql://user:password@host/dbname?sslmode=require
```

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
